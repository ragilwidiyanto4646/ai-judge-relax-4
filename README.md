## The entry

A short text about a pendulum running down in a clockmaker's workshop. The calm comes from the scene itself, never from being told to relax: the pendulum's tick is a concrete repeating anchor that returns again and again, each time a touch later than the last, the brass bob rising a little less high, the sound softer against the wooden case, until the last tick is barely a sound at all. The sentences shorten toward the end, so the reading itself slows down.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` is Python 3.13, standard library only, and deterministic: both runs write the same bytes to `entry.txt` (604 characters, four paragraphs).
